감이 아닌 채널 데이터, 댓글, 저장, 조회 흐름 기반 기획. 팀이 이해할 수 있는 근거로 정리.
02
합의된 범위 안의 빠른 구현
기획서에 그치지 않고 합의된 브랜드 톤과 목표 안에서 시안·실행물로 신속한 전환.
03
반복 업무 템플릿화
소재 탐색, 발행, 리포팅 과정의 구조화를 통한 팀 시간 절감과 다음 실험 집중.
CONTENT SYSTEM

콘텐츠 변수를 운영하는 방식

계정별 상수를 우선 파악하고 성과 변수를 더해 콘텐츠 브랜드를 구축. 가설, 제작, 발행, 지표 확인, 인사이트 공유, 다음 실험의 루프로 운영. 반응이 확인된 콘텐츠는 예약 문의·캠페인·매출 기회로 연결.

01
Empathy Variable
타깃이 자기 이야기로 받아들일 감정 변수 정의와 브랜드 톤 안의 표현.
02
Curiosity Variable
첫 1초·상황·훅을 시리즈 포맷으로 정리해 반복 실험.
03
Fan Immersion Variable
팬덤의 감정 언어와 브랜드 메시지를 연결한 몰입형 콘텐츠 룰 구축.
OPERATING LOOP
가설 설정 → 제작 → 발행 → 지표 확인 → 인사이트 공유 → 다음 실험
WORKING STYLE

새로운 브랜드의
맥락 우선 파악과 작은 검증

기존 성과 방식을 무조건 적용하지 않고 브랜드의 톤, 고객, 승인 기준, 팀 업무 방식을 우선 이해. 작은 실험으로 반응을 확인한 뒤 다음 담당자가 이어 쓸 수 있는 형태로 구조화.

01
Context First
브랜드 톤, 기존 채널, 타깃, 내부 승인 방식, 리포팅 기준 우선 파악.
02
Small Test
기존 콘텐츠 반응 기반의 작은 포맷 실험 제안과 제작·발행 흐름에 맞춘 실행.
03
Reusable System
성과 포맷을 콘텐츠 캘린더, 리포트, 다음 실행안으로 정리해 반복 가능한 운영 구조로 전환.
